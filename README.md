# 📊 Mobile Sales Insights Dashboard

## 📌 Project Overview

This Power BI dashboard provides a comprehensive analysis of mobile sales performance across different brands, cities, and customer segments. It leverages advanced DAX calculations and interactive visualizations to track key business metrics, identify sales trends, and support data-driven decision-making.

## 🎯 Objectives

- Monitor overall sales performance
- Track Month-to-Date (MTD) sales metrics
- Compare sales with the Same Period Last Year (SPLY)
- Analyze brand and model performance
- Understand customer purchasing behavior
- Identify regional sales trends

## 📈 Key KPIs

- 💰 Total Sales
- 📦 Total Quantity Sold
- 🛒 Total Transactions
- 📊 Average Selling Price
- 📅 Month-to-Date (MTD) Sales
- 🔄 Same Period Last Year (SPLY) Comparison


## 🔍 Dashboard Features

- Brand-wise Sales Analysis
- Mobile Model Performance Tracking
- City-wise Sales Distribution
- Customer Rating Analysis
- Payment Method Analysis
- Monthly Sales Trend Visualization
- Interactive Filters and Slicers
- Dynamic KPI Monitoring

## 🛠️ Tools & Technologies

- Power BI
- DAX
- Microsoft Excel
- Data Modeling
- Time Intelligence Functions

## 📂 Dataset

The dataset contains mobile sales transaction data including:
- Sales Amount
- Product Details
- Customer Ratings
- Payment Methods
- Transaction Information
- Location Data
